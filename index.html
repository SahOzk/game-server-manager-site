Planned features

Designed for everyday administration from a gaming PC or phone.

Independent profiles

Separate worlds, configuration and files for each dedicated game server profile.

Resource safety

A backend-enforced single-server limit and memory limits based on available resources.

Mod management

Planned Modrinth and CurseForge integration, dependency checks, compatibility validation and permission-respecting downloads.

Safer updates

No automatic updates for existing profiles, with confirmation and backup before manual updates.

Browser configuration

Manage supported game settings and edit configuration files from desktop or mobile.

Player administration

Moderation, permissions, allow lists and bans in a unified interface.

Project status

An interactive frontend prototype exists. Live server management, file editing, remote mod downloads and hardware monitoring are still under development. CurseForge API integration will only operate with approved access and respect mod authors' download permissions and API requirements.
